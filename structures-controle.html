Jusqu'à condition

Une condition vaut Vrai ou Faux. Comparaisons : = ≠ < > ≤ ≥. Opérateurs logiques : ET, OU, NON. a mod b donne le reste de la division entière, a div b le quotient entier.

Pour : nombre de répétitions connu. Tant que : teste avant chaque tour, le corps peut ne jamais s'exécuter. Répéter : teste après chaque tour, le corps s'exécute au moins une fois.

Au clavier, tapez >= et <= pour ≥ et ≤, <- pour ←. Les majuscules et les accents ne comptent pas.

Exercice 2 · Lire une alternative

3 points
Algorithme Parite
Variables n : Entier
Début
    Lire(n)
    Si n mod 2 = 0 Alors
        Afficher("pair")
    Sinon
        Afficher("impair")
    FinSi
Fin

Qu'affiche l'algorithme lorsque l'utilisateur saisit :

n = 14
n = 7
n = 0

Voir la correction

14 → pair · 7 → impair · 0 → pair.

14 mod 2 = 0 et 0 mod 2 = 0 : la condition est vraie. 7 mod 2 = 1 : la condition est fausse, le bloc Sinon s'exécute.

L'algorithme affiche la mention d'une moyenne : « Bien » à partir de 14, « Passable » de 10 à moins de 14, « Insuffisant » en dessous de 10. Complétez les 3 trous :

    ......(2)......

    ......(3)......
Fin
(1)
(2)
(3)

Tests : que s'affiche-t-il pour chaque moyenne saisie ?

14
11,5
9

Voir la correction

(1) Sinon Si · (2) Sinon · (3) FinSi. Tests : 14 → Bien · 11,5 → Passable · 9 → Insuffisant.

Les conditions sont testées dans l'ordre : 11,5 échoue à la première puis vérifie la deuxième ; 9 échoue aux deux et tombe dans Sinon.

Exercice 6 · Saisie contrôlée

4 points

Énoncé : écrire un algorithme qui demande une note sur 20 et la redemande tant qu'elle n'est pas valide (une note valide est comprise entre 0 et 20 inclus). Quand la note est valide, il affiche « Note enregistrée : » suivi de la note.

① Condition qui indique qu'une note est valide

② Algorithme complet (déclaration, boucle, affichage)

③ L'utilisateur saisit successivement 25, −3 puis 14

Exécutions de Lire
Note enregistrée

La vérification de l'algorithme repère les éléments attendus (déclaration, boucle, Lire, condition correcte, Afficher). Elle ne remplace pas la relecture du professeur.

Voir la correction

① note >= 0 ET note <= 20

Algorithme SaisieControlee
Variables note : Réel
Début
    Répéter
        Afficher("Entrez une note sur 20 :")
        Lire(note)
    Jusqu'à note >= 0 ET note <= 20
    Afficher("Note enregistrée : ", note)
Fin

Autre solution avec Tant que (condition inversée : la note est invalide) :

Lire(note)
Tant que note < 0 OU note > 20 faire
    Afficher("Note invalide")
    Lire(note)
FinTantQue
Afficher("Note enregistrée : ", note)

③ 25 et −3 sont refusées, 14 est acceptée : 3 lectures, note enregistrée 14. Erreur fréquente : écrire OU au lieu de ET dans la condition de validité.
